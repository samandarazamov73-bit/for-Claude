# Что нужно для игры (модели, текстуры, звуки, решения)

Всё, что сейчас в игре, — **заглушки**, сделанные кодом. Каждую можно заменить файлом:
положи файл с нужным именем в папку `assets/…` и перезапусти страницу. Ничего
прописывать не нужно — на экране загрузки видно, что взято из файла, а что пока заглушка.

## 1. 3D-модели — `assets/models/`

Формат для всех: **GLB** (glTF binary), 1 единица = 1 метр, экспорт из Blender со
стандартной галочкой *+Y Up*. **Без Draco-сжатия** (пока не подключено).
Текстуры — внутри GLB, до 2048×2048. Размер не важен: игра сама подгоняет по длине/высоте.

**Куда смотрит модель.** В Blender нос автобуса (лицо персонажа, вход больницы) должен
смотреть **в сторону +Y** — то есть *от* зрителя в виде *Front* (цифра 1).
Если в игре модель окажется задом наперёд — в `src/assets.js` поставь ей `rotationY: 3.14159`
(или просто скажи мне).

| Файл | Что это | Требования |
|---|---|---|
| `bus.glb` | **Автобус: кузов + салон** | Низкопольный городской, ~12 м. Внутри: сиденья, поручни, место для коляски напротив средней двери. Двери и пандус — **отдельными объектами** с именами ниже, иначе они не будут двигаться. До ~150 тыс. треугольников. |
| `wheelchair.glb` | Электроколяска | ~1.05 м длиной, начало координат — на земле под осью ведущих колёс. Колёса отдельными объектами (если хочешь, чтобы крутились — скажи, подключу по именам). |
| `hero.glb` | Главный герой | В позе сидя (или с анимацией `Sitting`), таз — на высоте ~0.55 м над землёй, чтобы садился на коляску. |
| `mom.glb` | Мама | С ригом и анимациями **`Idle`**, **`Walking`**, **`Sitting`** (подойдут из Mixamo — названия клипов можно поменять в `src/assets.js`). |
| `hospital.glb` | Здание больницы | Вход — с фасада, смотрящего «вперёд». Игра поставит его входом к дороге. Площадь, пандус и лестница остаются из игры. |

### Имена объектов внутри `bus.glb` (необязательно, но лучше так)
| Имя объекта | Зачем |
|---|---|
| `door_front_left`, `door_front_right` | створки передней двери (анимация открытия) |
| `door_middle_left`, `door_middle_right` | створки средней двери |
| `ramp` | откидной пандус (поворот вокруг петли у порога) |
| `anchor_wheelchair` | пустышка (Empty): где стоит коляска; её поворот — куда смотрит герой |
| `anchor_mom_seat` | пустышка: где сидит мама |
| `anchor_door_middle` | пустышка: середина средней двери на уровне пола |
| `driver` | если водитель уже в модели — тогда заглушка водителя скрывается |

## 2. Текстуры — `assets/textures/` (`.jpg`, `.png` или `.webp`)
Бесшовные (tileable), 1024–2048 px.

| Файл | Что | Сколько метров на один повтор |
|---|---|---|
| `road` | асфальт | 6 м |
| `sidewalk` | тротуарная плитка | 1.2 м |
| `grass` | трава | 5 м |
| `concrete` | бордюр / бетон | 1 м |
| `facade0`, `facade1`, `facade2` | фасад жилого дома: **один пролёт — одно окно на один этаж (3×3 м)**, стена светлая (цвет дома задаётся игрой) | 3 м |
| `hospital_facade` | фасад больницы (такой же пролёт) | 3 м |
| `bus_seat` | ткань сидений | 0.4 м |
| `bus_floor` | пол автобуса | 1.2 м |

## 3. Звуки — `assets/sounds/` (`.mp3`, `.ogg` или `.wav`)
Сейчас все звуки синтезируются. Настоящие сильно поднимут атмосферу.

| Файл | Что | Тип |
|---|---|---|
| `engine` | двигатель автобуса **изнутри салона** (ровные обороты; тон игра меняет сама) | петля |
| `road` | шум колёс по асфальту | петля |
| `interior` | фон салона: вентиляция, гул | петля |
| `city` | улица: машины вдали, голоса | петля |
| `birds` | птицы у больницы | петля |
| `wheelchair_motor` | жужжание мотора электроколяски | петля |
| `music` | музыка (если нужна) | петля |
| `door` | пневматика дверей (шипение) | разовый |
| `beep` | писк перед закрытием дверей | разовый |
| `bell` | звонок кнопки «остановка» | разовый |
| `chime` | гонг автоинформатора | разовый |
| `tick` | щелчок поворотника | разовый |
| `ramp` | пандус (мотор + писк) | разовый |

**Озвучка реплик** (голоса мамы, водителя, автоинформатора) пока не подключена —
сейчас только субтитры. Если будут записи, подключу: по файлу на реплику.

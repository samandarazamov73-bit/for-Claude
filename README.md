# Дорога — пролог (3D, браузер)

Главный герой — парень на электроколяске. Игра начинается в пути: вместе с мамой он едет
в больницу на городском автобусе (3–5 минут). Автобус проходит остановки, стоит на
светофоре, пассажиры выходят и входят, мама разговаривает с сыном (есть выбор ответов).
У больницы автобус останавливается, экран темнеет, откидывается пандус, мама и коляска
выходят, автобус уезжает — и дальше игрок сам едет на коляске к входу в больницу.

## Как запустить
- **Windows**: двойной щелчок по `start.bat` (нужен Python 3 с python.org).
- **Mac / Linux**: `./start.sh`.
- Открыть `http://localhost:8080`.

Двойной щелчок по `index.html` не сработает: браузер не даёт открытому с диска файлу
загружать модули и 3D-модели.

## Управление
| Клавиша | Действие |
|---|---|
| мышь (после щелчка по экрану) | осмотреться |
| E / ЛКМ | поговорить с мамой, нажать кнопку вызова |
| 1 2 3 | выбрать ответ |
| Enter | пропустить реплику |
| V | вид из коляски / снаружи автобуса |
| F (держать) | перемотка поездки ×8 |
| W A S D, Shift | ехать на коляске (на улице), быстрый режим |
| M | звук | 
| Esc / P | пауза |

## Где что менять
| Файл | Что там |
|---|---|
| `src/story.js` | **все тексты**: реплики, выборы, остановки, задания |
| `src/config.js` | скорость автобуса, стоянки, светофор, скорость коляски, графика |
| `assets/` | твои модели, текстуры и звуки — см. **ASSETS.md** |
| `src/route.js` | форма маршрута (повороты, где остановки) |
| `src/world.js` | город, остановки, парк, рынок, территория больницы |
| `src/bus.js` | автобус-заглушка, двери, пандус, табло, кнопка |
| `src/characters.js` | человечки-заглушки, электроколяска |
| `src/main.js` | сценарий поездки, катсцена прибытия, управление на улице |

## Для разработки
- `?debug=1` — панель состояния и кнопки «к светофору / к больнице / прибытие / улица».
- `?minutes=3` — длина поездки; `?autostart=1` — без меню; `?skipto=arrival` — сразу к прибытию.
- Длина маршрута подбирается автоматически, чтобы поездка шла ровно выбранное время.

Сторонний код: [three.js](https://threejs.org) r160 (MIT) лежит в `vendor/three/` — интернет не нужен.
Прежняя 2D-игра Spider Swing осталась в истории git.

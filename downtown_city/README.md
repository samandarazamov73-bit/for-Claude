# Downtown City — Godot 4.x

Интерактивный 3D-город, воссозданный по трейлеру **Quaternius Downtown City MegaKit**
(перекрёсток с *The Jade Garden*, башня *Paul & Sons Bakery*, *PA Savings Bank Building*,
главная авеню с берёзами, разметкой *STOP / ONLY ↑* и T-образным перекрёстком в конце)
и расширенный до сетки из 35 кварталов (~580 × 480 м) с силуэтом города вокруг.

Подробный разбор видео и карта города — в [CITY_PLAN.md](CITY_PLAN.md).

## Запуск

1. Godot **4.4+** (проверено на 4.4.1, рендерер Forward+; на Mac M1 — Metal).
2. Открыть папку `downtown_city/` в редакторе (при первом открытии Godot импортирует
   модули кита и текстуры — это ~1 минута).
3. F5. Генерация города занимает несколько секунд.

## Управление

| Клавиша | Действие |
|---|---|
| ЛКМ / ПКМ + мышь | вращение вокруг точки (режим Orbit) |
| Shift + ЛКМ, СКМ | перемещение (pan) |
| Колесо | приближение / отдаление |
| WASD / стрелки, Q/E, Shift | движение, поворот, ускорение |
| **1** | Orbit (по умолчанию) |
| **2** | Вид сверху (ортографическая карта) |
| **3** | Свободный полёт (зажать ПКМ для обзора, Space/C — вверх/вниз) |
| **4** / G | Прогулка персонажем (Space — прыжок, V — 1-е/3-е лицо) |
| **R** / Home | Сброс камеры в исходный ракурс из видео |
| **N** | Время суток: день / золотой час / сумерки / ночь |
| **F2** | Качество: low / medium / high |
| **F3** | Статистика (FPS, draw calls, треугольники, VRAM) |
| **F4** | Адаптивное разрешение вкл/выкл |
| **H** | Скрыть подсказку |
| **F12** | Скриншот в `user://screenshots` |

## Производительность (цель — Apple M1, 30+ FPS)

* **Инстансинг**: все модули кита и пропсы рисуются через `MultiMeshInstance3D` —
  один вызов отрисовки на тип модуля в квартале.
* **HLOD**: детальные фасады из модулей видны до ~175 м; дальше квартал заменяется
  объединённой «оболочкой» с процедурным шейдером окон (`shaders/facade_far.gdshader`).
  Мелкие пропсы — до 95 м, деревья/фонари — до 340 м.
* **Тени**: здания отбрасывают тени через невидимые прокси-боксы (несколько сотен
  треугольников на квартал) вместо тысяч модулей; детальные тени — на пресете High.
* **Окна**: интерьеры комнат — один шейдер interior mapping без текстур и без прозрачности.
* **Разметка** дорог — процедурная в шейдере асфальта (без декалей).
* **Адаптивное разрешение**: при падении FPS ниже ~33 внутреннее разрешение снижается
  (FSR 1.0 апскейл), при запасе — повышается обратно.
* Текстуры импортируются с VRAM-сжатием и мипмапами (`textures/*.import`).
* Ночные фонари: пул из 10–16 `OmniLight3D`, которые переставляются к ближайшим к камере
  фонарям; остальные фонари — только эмиссия + glow.

Пресеты (`scripts/environment_controller.gd`): **medium** по умолчанию — масштаб рендера
0.8 + FSR, тени 4096 / 2 каскада / 200 м, SSAO половинного разрешения, glow, FXAA.

## Структура

```
downtown_city/
├── project.godot
├── scenes/main.tscn              — основная сцена
├── scripts/
│   ├── main.gd                   — запуск, ввод, скриншоты
│   ├── city_generator.gd         — сетка улиц, кварталы, участки, «героические» здания, пропсы
│   ├── building_generator.gd     — грамматики фасадов из модулей кита, крыши, LOD-оболочки
│   ├── prop_factory.gd           — деревья, фонари, светофоры, пожарные лестницы, маркизы, вывески
│   ├── city_chunk.gd             — батчинг квартала: MultiMesh, меши, коллизии, дальности видимости
│   ├── kit_library.gd            — загрузка модулей кита и замена материалов
│   ├── city_materials.gd         — все материалы
│   ├── geo_batch.gd              — построитель процедурной геометрии
│   ├── environment_controller.gd — небо, солнце, время суток, качество, адаптивное разрешение
│   ├── camera_controller.gd      — режимы камеры
│   ├── player.gd                 — персонаж (models/characters/explorer.glb)
│   ├── night_lights.gd, hud.gd
├── shaders/                      — стены, лепнина, металл, интерьеры окон, дорога, тротуар,
│                                   дальние фасады, листва, небо, вывески
├── models/kit/                   — модули Downtown City MegaKit (подготовлены tools/prepare_kit.py)
├── models/characters/            — персонаж
├── textures/                     — сгенерированные PBR-текстуры, вывески, разметка
├── tools/                        — генераторы и dev-сцены (каталог модулей, тест зданий)
└── CITY_PLAN.md
```

## Пересборка ассетов

```bash
# модули кита из репозиториев с ассетами
python3 tools/prepare_kit.py ../osoososos ../osoososos2 models/kit
# текстуры (нужны Pillow, numpy; шрифты Noto CJK и URW base35 для вывесок)
python3 tools/gen_textures.py .
python3 tools/write_import_files.py .
```

## Как продолжать разработку

* Новые стили фасадов — словарь `STYLES` в `building_generator.gd`.
* Размер города — `X_LINES` / `Z_LINES` / `AVENUES` / `STREETS` в `city_generator.gd`.
* Все здания, улицы и тротуары имеют коллизии (боксы/цилиндры), персонаж — `CharacterBody3D`.
* Транспорта и пешеходов в трейлере нет, поэтому они не добавлены; точки для них легко
  получить из сетки улиц (`AVENUES`, `STREETS`, `ROAD_HALF`).

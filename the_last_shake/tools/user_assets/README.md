# Подготовка присланных текстур, картинок, моделей и звуков

Скрипты чинят то, что пришло с Google Drive, **до** установки в игру. Исходники не меняются: результат пишется в отдельную папку.

## Порядок

1. **Скачать папку с Drive.** Сначала получить список файлов, затем скачать каждый файл через `drive.usercontent.google.com`:
   ```bash
   gdown --json "<ссылка на папку>" > list.json
   ```
   ```bash
   python3 drive_dl.py list.json <куда>
   ```
2. **Текстуры стен, полов и фасада.** Результат лежит в `<out>/<имя материала в игре>/`, карты albedo, normal_gl, height, roughness, ao, orm.
   - `fix_glare.py <tex> <out>` убирает блик, нарисованный прямо в цвете и во всех картах голубой и персиковой стены, и делает бежевую стену перекраской персиковой.
   - `fix_seams.py <tex> <out>` убирает швы: обрезает текстуру по периоду рисунка (кафель, ромбы, плитка, кирпич) и сшивает края по линии наименьшей разницы. У фасада по X только выравнивает цвет на стыке, потому что панели там уже совпадают.
   - `copy_rest.py <tex> <out>` раскладывает остальные материалы, которым правка не нужна. Потолок берёт ту же штукатурку.
3. **Картинки.**
   - `fix_pics.py <pics> <out>` делает настоящую прозрачность вместо чёрного или белого фона и цветного ореола, подрезает одиночные предметы.
   - `fix_dial.py <out>/phone_dial` пересобирает диск телефона с 10 отверстиями, на исходнике не было девятки.
   - `make_citramon.py <out>/med_boxes <out>/med_citramon` делает коробку «Цитрамон» из коробки «Анальгин».
4. **Модели.** Скрипт запускается в Blender (bpy):
   ```bash
   python -c "import sys; sys.argv=['x','<glb>','<out>']; exec(open('fix_models.py').read())"
   ```
   Он делает следующее:
   - разрезает файлы, где лежит несколько предметов (кресла, тумбочки, столики), и выравнивает их фасадом вперёд;
   - разворачивает кровать, ванну и остановку;
   - приводит всё к настоящему размеру;
   - ставит точку опоры на пол под центром, у подвесных ламп — сверху.
5. **Звуки.** `fix_sounds.py <wav> <out>` даёт игровые имена (варианты `_2`, `_3`), 44,1 кГц, обрезает тишину, выравнивает пик до −1 дБ и склеивает петли без щелчка.
6. **Проверка моделей.** `glb_preview.gd` — Godot-скрипт, рисует каждую модель спереди, справа, сзади и сверху:
   ```bash
   godot -s glb_preview.gd -- --src=<glb> --out=<png>
   ```

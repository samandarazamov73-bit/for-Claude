THE LAST SHAKE
Psychological horror · Oromgoh Sanatorium, Tashkent, 1975
Game and story — Saman

============================================================
ENGLISH
============================================================
HOW TO START
  Windows: unzip the folder and run TheLastShake.exe.
           Keep TheLastShake.pck next to the .exe.
           If Windows shows "Windows protected your PC": click
           "More info" -> "Run anyway" (the game is not signed).
  macOS:   unzip, drag "The Last Shake.app" to Applications.
           First launch: right-click the app -> Open -> Open.
           macOS 15+: if it still refuses, open System Settings ->
           Privacy & Security -> "Open Anyway".
           (Or in Terminal: xattr -cr "/Applications/The Last Shake.app")
  Linux:   unzip, then run ./TheLastShake.x86_64
           (if needed: chmod +x TheLastShake.x86_64)

LANGUAGE: Settings -> Language (English / Русский / O'zbekcha).
CONTROLS: W/S drive, A/D turn, mouse look, E interact, F flashlight,
          Q/R wheelchair speed, Space skip line, Esc pause.
          All keys: main menu -> Controls.
SAVES:    the game remembers the chapter you reached ("Continue").
NEEDS:    a graphics card with Vulkan (Windows/Linux) or Metal (Mac),
          8 GB RAM, ~2.5 GB free disk space. Headphones recommended.
CONTENT:  violence, strong language, death, disturbing scenes.

РУССКИЙ

КАК ЗАПУСТИТЬ
  Windows: распакуйте папку и запустите TheLastShake.exe.
           Файл TheLastShake.pck должен лежать рядом с .exe.
           Если Windows пишет «Система Windows защитила ваш компьютер»:
           «Подробнее» -> «Выполнить в любом случае» (игра без подписи).
  macOS:   распакуйте и перетащите «The Last Shake.app» в «Программы».
           Первый запуск: правый клик по приложению -> «Открыть» -> «Открыть».
           macOS 15 и новее: если всё равно не открывается — «Системные
           настройки» -> «Конфиденциальность и безопасность» -> «Всё равно открыть».
           (Или в Терминале: xattr -cr "/Applications/The Last Shake.app")
  Linux:   распакуйте и запустите ./TheLastShake.x86_64
           (если нужно: chmod +x TheLastShake.x86_64)

ЯЗЫК:       Настройки -> Язык (Русский / English / O'zbekcha).
УПРАВЛЕНИЕ: W/S — ехать, A/D — поворот, мышь — смотреть, E — действие,
            F — фонарик, Q/R — скорость коляски, Пробел — пропустить реплику,
            Esc — пауза. Все клавиши: главное меню -> «Управление».
СОХРАНЕНИЕ: игра помнит главу, до которой вы дошли («Продолжить»).
НУЖНО:      видеокарта с Vulkan (Windows/Linux) или Metal (Mac),
            8 ГБ памяти, ~2,5 ГБ на диске. Лучше в наушниках.
ВНИМАНИЕ:   насилие, нецензурная брань, смерть, тяжёлые сцены.

# Как выложить игру на сайт (itch.io)

Готовые архивы:
- `TheLastShake_Windows.zip` — для Windows
- `TheLastShake_macOS.zip` — для Mac (Intel и Apple M1/M2/M3…)
- `TheLastShake_Linux.zip` — для Linux

В каждом лежит `README_PLAYERS.txt` — как запустить (на трёх языках).

## itch.io (бесплатно)
1. Зарегистрируйся на https://itch.io → справа вверху меню → **Upload new project**.
2. **Title**: The Last Shake. **Kind of project**: Downloadable. **Pricing**: бесплатно,
   «No payments» или «$0 or donate».
3. **Uploads → Upload files**: загрузи три архива. Под каждым отметь платформу:
   Windows / macOS / Linux (галочки под файлом).
4. **Description**: текст из `ITCH_PAGE.md` (английский — наверху, русский и узбекский — ниже).
5. **Cover image**: `cover_630x500.png`. **Screenshots**: 3–5 кадров из игры.
6. **Genre**: Horror, **Tags**: из `ITCH_PAGE.md`. Отметь **Content warnings**.
7. **Visibility**: сначала «Draft» → «Save» → открой страницу, скачай и проверь сам. Потом «Public».

Большие файлы (больше 1 ГБ) через сайт может не принять — тогда загружай программой
**butler** (https://itch.io/docs/butler/): `butler push TheLastShake_Windows.zip <ник>/the-last-shake:windows`.

## Пересобрать самому (если поменяешь игру)
В Godot: **Editor → Manage Export Templates → Download and Install** (один раз),
потом **Project → Export → Export All**. Настройки трёх сборок уже лежат в `export_presets.cfg`,
файлы появятся в папке `build` рядом с проектом.

## Предупреждения, которые увидят игроки
- **Windows**: «Система Windows защитила ваш компьютер» — игра не подписана. «Подробнее → Выполнить в любом случае».
  Убрать можно только платной подписью кода.
- **Mac**: «не удаётся проверить разработчика» — правый клик → «Открыть». Убрать — Apple Developer ($99 в год) и нотаризация.
